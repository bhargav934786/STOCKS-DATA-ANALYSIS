
# 📊 Stock Data Analysis Dashboard – Power BI
This project focuses on analyzing **Adani Enterprises Limited stock market data** using Microsoft Power BI. The dashboard provides interactive visualizations to monitor stock performance, compare opening and closing prices, analyze trading volume, and track 52-week high and low prices.

The objective is to transform stock market data into meaningful insights through interactive dashboards and time-based analysis.

## 🎯 Objectives
- Analyze historical stock price movements.
- Compare opening and closing stock prices.
- Monitor trading volume across different months.
- Track 52-week high and low stock prices.
- Identify stock performance trends over time.
- Enable interactive analysis using date-based filters.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** – Dashboard development and data visualization.
- **Power Query** – Data preparation and transformation.
- **Data Visualization** – KPI Cards, Line Charts, Column Charts and Combo Charts.

## 📈 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- Opening Price
- Closing Price
- Trading Volume
- 52-Week High
- 52-Week Low

### 2. Stock Price Analysis
- Opening vs. closing price trends.
- Daily stock price movement.
- Historical stock performance analysis.
- Comparison of 52-week high and low prices.

### 3. Trading Volume Analysis
- Monthly trading volume comparison.
- Identification of high-volume trading periods.
- Analysis of volume trends over time.

### 4. Interactive Filters
The dashboard includes interactive slicers:
- Day
- Month
- Quarter
- Year

These filters allow users to explore stock market performance across different time periods.

## 📊 Power BI Visualizations
- KPI Cards
- Line Charts
- Clustered Bar Charts
- Column Charts
- Line and Stacked Column Combo Charts
- Interactive Slicers

## 💡 Key Insights
The dashboard helps users:
- Understand stock price fluctuations.
- Compare opening and closing prices.
- Monitor monthly trading activity.
- Track stock price highs and lows.
- Explore historical trends using interactive filters.

## 📂 Project Files
- `STOCK DATA ANALYSIS.pbix` – Power BI dashboard file.

## 🚀 How to Use This Project
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard and KPI cards.
4. Use Day, Month, Quarter and Year slicers to filter the data.
5. Analyze stock price and trading volume trends.
